# P5R 动效设计

5.72.0 使用 React 和 Framer Motion 编排菜单展示。准备页以新岛真的漫画剪影和红白分色前臂为中心，真实菜单沿白色手掌与前臂排列，和插画共用坐标与缩放比例；内容页保留较弱的侧边插画。人物、标题、选中项和正文之间保持主次，字形变化集中在词组内部。

主导航用细白刀光与标题落位表达切换。曲线统一采用 `cubic-bezier(0.16, 1, 0.3, 1)`；悬停指针使用三次短促的阶跃微动。背景插画与正文保持稳定，没有整屏闪白或重复遮罩。关闭动效后停止这些演出，仍可正常操作。

侧栏与准备页的女性头像横条分别约每秒 12 px 与 18 px。支持悬停、键盘聚焦和独立按钮暂停，以及鼠标拖动、触摸滑动、横向触控板和方向键浏览。根据视口宽度补足循环副本，避免宽屏原生滚动被提前截断；横条与窗口拖动相互独立。

## 参考与边界

- [P5 美术总监须藤正喜的界面设计访谈译文](https://personacentral.com/persona-5-interview-ui-design-sound-music/)：先确定构图与各部件的反应方式，强调菜单即时响应。
- [P5 原版菜单与战斗界面的动图分析](https://jiaxinwen.wordpress.com/2017/04/27/the-ui-design-of-persona-5/)：本次提取了菜单开启动图的时间序列，核对人物、菜单与背景的运动层级。这是 2017 年 P5 素材，不能当成 Royal 独有动画的逐帧依据。
- [P5R 菜单实录参考入口](https://www.youtube.com/watch?v=FsP9FcYhnmw)：Royal 的菜单角色入场演出。本次环境未能读取该视频，不宣称逐帧复刻。
- [q-mona/p5-ui](https://github.com/q-mona/p5-ui)：核对拼贴文字、局部选择反馈和现有女性 Q 版素材；该组件库不提供原游戏完整菜单转场。

本版使用用户提供的游戏菜单截图作为构图参考，并通过 GPT-Image 生成新岛真衍生插画。实际菜单、标题、按钮与表单由代码渲染，图片不包含文字或控制器提示。这是适合表单型插件的改编，没有复制游戏的 3D 人物动作，也不宣称对原游戏逐帧复刻。

## 动作关系

| 操作 | 行为 |
| --- | --- |
| 展开手册 | 展开窗口边界，细白刀光切入；导航、标题与小图标依次落位。窗口本身不旋转。 |
| 切换主栏目 | 导航立即选中；标题从 1.4 倍快速收势，小图标稍晚落位，背景固定。按栏目顺序确定左右方向，约 285 ms 内结束。 |
| 进入二级页、返回 | 只处理页头和线条，返回方向相反；不重播图标入场。 |
| 进入人物或玩法编辑 | 局部标题反馈；输入框、按钮和正文不位移、不被盖住。 |
| 打开弹窗 | 原位显现并收拢纸片阴影，不旋转或横甩整个表单。 |
| 勾选、输入、展开说明、数据刷新、切换聊天 | 不触发页面演出。 |
| 连续导航、收起 | 取消上一段页面动画，从最新状态继续；无动画队列。 |
| 悬停或键盘聚焦 | 小幅放大与红黑反馈，白色指针从左侧切入；微震动三次后停止。 |

阅读区域始终完全不透明，滚动容器保持固定。动画结束或取消后恢复临时内联样式，防止窗口关闭时的裁切残留到再次展开。页面转场都有明确终点；只有头像横条持续低速移动，可单独暂停。关闭界面动效或启用系统减少动态效果时，停止自动滚动，保留手动浏览。窗口关闭、横条离开可视区域或浏览器页面隐藏时停止更新；停用扩展释放 React 根节点、事件、观察器与动画帧。

## 复现与验证

```sh
npm run preview
# 另一个终端：
npx playwright install ffmpeg
CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-motion.mjs
# 单独录制头像自动滚动与手动浏览：
CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-reels.mjs
```

录屏输出到 `release/motion-preview/`，包含桌面和手机的展开、主导航、进入详情、返回、收起和重新展开。使用模拟宿主与示例数据，不调用模型。

头像演示输出到 `release/portrait-preview/`，展示桌面两处自动滚动、悬停暂停与拖动，以及手机触摸滑动。

浏览器回归覆盖前进与返回的运动方向、正文透明度与位置、聊天载入和数据刷新不重播导航、桌面拖动和位置记忆，以及头像循环衔接、暂停偏好、手动输入和生命周期。截图与录屏使用模拟宿主，不包含真实模型调用；手机手势是 Chromium 模拟，未做真机验证。
