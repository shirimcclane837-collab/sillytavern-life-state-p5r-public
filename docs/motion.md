# P5R 动效设计

5.71.0 将开窗、切页、二级导航、角色切换套用同一段三色遮罩，还叠加整块内容变淡、卡片斜切和错位入场。高对比区域反复覆盖阅读内容，动作之间缺少主次。5.71.1 删除了这套遮罩及逐卡片入场，保留默认开启的动效，重新区分操作层级。

5.71.3 统一了顶栏、侧栏和内容背景，删除红色装饰角块与头像相框。底面保持固定，继续使用标题、剪影和导航的局部入场与操作反馈。

5.71.4 按需求为侧栏与准备页的女性头像横条加入低速循环滚动，分别约每秒 12 px 与 18 px。支持悬停、键盘聚焦和独立按钮暂停，以及鼠标拖动、触摸滑动、横向触控板和方向键浏览。循环衔接处没有空档，横条与窗口拖动相互独立。

## 参考与边界

- [P5 美术总监须藤正喜的界面设计访谈译文](https://personacentral.com/persona-5-interview-ui-design-sound-music/)：先确定构图与各部件的反应方式，强调菜单即时响应。
- [P5 原版菜单与战斗界面的动图分析](https://jiaxinwen.wordpress.com/2017/04/27/the-ui-design-of-persona-5/)：本次提取了菜单开启动图的时间序列，核对人物、菜单与背景的运动层级。这是 2017 年 P5 素材，不能当成 Royal 独有动画的逐帧依据。
- [P5R 菜单实录参考入口](https://www.youtube.com/watch?v=FsP9FcYhnmw)：Royal 的菜单角色入场演出。本次环境未能读取该视频，不宣称逐帧复刻。
- [q-mona/p5-ui](https://github.com/q-mona/p5-ui)：核对拼贴文字、局部选择反馈和现有女性 Q 版素材；该组件库不提供原游戏完整菜单转场。

本版用现有女性 Q 版图标、纸片标题和导航文字组织动效，属于适合表单型插件的改编。没有复制游戏里的 3D 人物动作，也没有把静态头像包装成新的角色动画。

## 动作关系

| 操作 | 行为 |
| --- | --- |
| 展开手册 | 220 ms 展开窗口边界；导航文字、标题、插图分层落位。窗口不旋转、不回弹。 |
| 切换主栏目 | 导航立即选中；标题小幅落位，女性剪影稍晚收势，背景固定。按栏目顺序确定左右方向，最长 285 ms。 |
| 进入二级页、返回 | 只处理页头和线条，返回方向相反；不重播图标入场。 |
| 进入人物或玩法编辑 | 局部标题反馈；输入框、按钮和正文不位移、不被盖住。 |
| 打开弹窗 | 原位显现并收拢纸片阴影，不旋转或横甩整个表单。 |
| 勾选、输入、展开说明、数据刷新、切换聊天 | 不触发页面演出。 |
| 连续导航、收起 | 取消上一段页面动画，从最新状态继续；无动画队列。 |

阅读区域始终完全不透明，滚动容器保持固定。页面转场都有明确终点；只有头像横条持续低速移动，可单独暂停。关闭界面动效或启用系统减少动态效果时，停止自动滚动，保留手动浏览。窗口关闭、横条离开可视区域或浏览器页面隐藏时停止更新，恢复时平稳继续；停用扩展会释放事件、观察器与动画帧。

## 复现与验证

```sh
npm run preview
# 另一个终端：
npx playwright install ffmpeg
CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-motion.mjs
# 单独录制头像自动滚动与手动浏览：
CHROMIUM_PATH=/usr/bin/chromium node scripts/capture-reels.mjs
```

录屏输出到 `release/motion-preview/`，包含桌面和手机的展开、主导航、进入详情、返回、收起和重新展开。使用模拟宿主与示例数据，不调用模型。

头像演示输出到 `release/portrait-preview/`，展示桌面两处自动滚动、悬停暂停与拖动，以及手机触摸滑动。

27 项浏览器回归测试通过，包含前进与返回的运动方向、正文透明度与位置、聊天载入和数据刷新不重播导航、桌面拖动和位置记忆，以及头像循环衔接、暂停偏好、手动输入和生命周期。另检查了桌面、手机截图与录屏；这些功能测试不代替审美评价。
